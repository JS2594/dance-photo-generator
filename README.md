# PopShot v8

私人课程合照封面生成器。GitHub Pages 静态部署即可使用。

## v8 重点
- MediaPipe Face Detector 优先进行多人主体识别，浏览器原生 FaceDetector 作为回退。
- 智能裁剪 + 照片手动拖拽/缩放兜底；换一版不会重置人工裁剪位置。
- 根据合照人数自动调整视觉拥挤度，尽量避免遮挡真人。
- 活力 / 酷飒 / 可爱 / 清爽 / Y2K 五套视觉主题。
- 标题、Q版人物、Logo、贴纸可拖动、缩放、隐藏、调层级、锁定、撤销/重做。
- 两周组合去重；同星期优先避免重复组合。
- 节日素材只在对应节日窗口出现，普通日期只使用通用素材。
- 记忆课程、美化、风格和未完成草稿；导出前状态检查。
- 输出尺寸 2525 × 1894。

> 第一次打开时，主体识别模块需要联网加载 MediaPipe；加载失败会自动回退，手动裁剪始终可用。

## V10.1 — Headline Module（本次优化）
### 裁剪修复
- 修复旧版 `smartCrop` 中宽、高被分别 clamp 导致照片**拉伸变形**的 bug；现在 4:3 比例在任何输入下都严格保持。
- 修复裁剪中心被"人体估算框"（向下延伸 6 倍脸高）带偏、导致人脸顶到画面上沿甚至出框的问题。
- 新逻辑：水平方向以**全体人脸中线**居中；垂直方向让人脸顶落在画面约 30% 处，上方自然留出标题带；如需保脚则下移裁剪窗，但头顶至少保留 14% 的标题空间。
- 手动拖拽/缩放兜底逻辑不变，且在新裁剪基础上叠加。

### 标题 × 人物真正成为一个模块
- 紧密组合（默认）模式重做：大标题**居中横贯顶部**，宽度随人数自适应（少人 84% / 中等 78% / 拥挤 72% 画面宽），字号自动放大到海报级别（ZUMBA 约 500px）。
- Q 版人物不再缩在角落，而是**骑在标题一端的字母上**（脚落在字母中下部），自动选择上半区人脸更少的一侧；若压到真人脸会自动缩小 20% 并上提。
- "布局"按钮循环切换：人物自动选边 → 强制左端 → 强制右端。
- "角落独立"模式保留旧版四套角落构图，供偏好者切换。
- 标题点选命中区改用实测宽高，居中标题也能准确拖动。

### 其他
- 贴纸默认关闭且移到右下角，仅"丰富"档或手动选择贴纸时出现，不再与大标题打架。
- 标题自适应缩窄不再永久改写图层 scale（旧版会越画越小）。
- 草稿恢复现在包含组合模式；版本号升级会自动清理旧草稿。
- Service Worker 缓存名与静态资源 query 已更新为 v10.1，GitHub Pages 部署后强刷一次即可生效。

## V10.2 — Graffiti Poster（针对实拍反馈的整改）
### 远景小脸识别（截图问题的根因）
- 实拍反馈中"保守智能裁剪"说明整图检测 0 命中：远景合照里人脸相对画面太小，短距模型认不出。
- 现在采用三遍检测：整图 → 2×2 重叠分块（脸的相对占比 ×1.8）→ 3×3 更小分块兜底，IoU 去重 + 中位数尺寸过滤误检（海报/倒影）。
- 即使全部失败，兜底裁剪也不再保留天花板：默认放大 1.22 倍、对准画面 58% 高度的中下主体带。
- 识别成功时裁剪边距进一步收紧（左右 1.15 脸高、下方 4.8 脸高），真人占画面比例明显提高。

### 花体标题引擎（全新）
- 每个字母独立旋转（±6°）、基线起伏、逐字配色，尾字母用第三亮色点睛（参考样图里黄色 A 的做法）。
- 五套样式全部重做：涂鸦多彩（深+白双描边+笔刷横扫底纹）/ 斜切刷线 / 白字残影 / 泡泡双边 / 贴纸拼贴（每个字母坐在彩色圆角贴纸上）。
- ZUMBA CAMP 的 CAMP 变成斜贴的小胶囊角标；此课程下人物默认站标题左端，不与角标打架。
- 每套风格新增第三个点缀色（活力=黄、酷飒=青、Y2K=冰蓝…）。

### 涂鸦与贴纸氛围
- 新增四角笔刷泼溅（品牌色+深色，"丰富"档四角全开，默认对角两处）。
- 新增手绘涂鸦：皇冠 / 爱心 / 星星 / 音符 / 闪光，沿边缘自动摆放并避开人脸；"换一版"会同时刷新泼溅与涂鸦布局。
- Q 版人物增加白色刀版贴纸描边，和标题、涂鸦形成统一的贴纸语言。

### 默认美颜打光
- 默认美化强度 38 → 55（老用户自动迁移一次），亮度/饱和映射整体上调。
- 新增柔光层：模糊副本以 screen 模式叠回，人物有柔和高光；拖动照片时自动跳过以保证流畅。

> 部署提示：整包替换后，先普通刷新一次让新 Service Worker 接管，再强刷（Cmd+Shift+R）即可看到右上角版本号 v10.2.0。若仍是旧界面，说明 GitHub Pages CDN 还没更新，等 1-2 分钟再试。

## V10.2.2 — 版本探针与更新提醒
- 新增 `version.json` 版本探针文件。页面在加载时、切回标签页时都会带时间戳拉取它（穿透浏览器缓存、Service Worker 和 GitHub Pages CDN），与当前运行版本比对。
- 顶部 PopShot 旁常驻版本徽标：绿色 `v10.2.2 ✓ 最新` = 页面就是线上最新；橙色 `v旧 → 线上已有 v新` = 后台文件已更新但页面还是旧的，同时弹出提示条，点"⟳ 立即更新"自动注销 Service Worker、清空缓存并重载。
- 顶部 🔔 按钮改为手动"检查更新"。
- **发布规则：每次发新版，`app.js` 里的 `VERSION` 和 `version.json` 里的 `version` 必须同步改成相同值**（本包已同步为 10.2.2）。

### 排查当前"始终是旧版"的问题
截图证据表明线上仍是 v10.0（标题样式面板还是旧的五个名字），说明 10.1/10.2 从未成功部署。请依次确认：
1. 仓库文件是否真的被新包覆盖（GitHub 网页上打开 app.js，搜 `VERSION`，应为 `10.2.2`）；
2. commit 是否 push 成功；
3. 仓库 Actions 标签页里 pages-build-deployment 是否在 push 后跑绿；
4. 以上都对但页面仍旧 → 等 2 分钟 CDN 刷新，之后版本徽标和更新提醒会自动接管这个判断。

## V10.3.0 — Local Face + 视觉细调
### 本地人脸识别（重要）
- 定位到"永远识别不到人脸"的真正原因：MediaPipe 模型托管在 storage.googleapis.com，国内网络加载不了，检测从未真正运行。
- 新增完全本地化的 pico.js 检测器（public/vendor/，~240KB，随仓库部署，零外网依赖）。MediaPipe 改为限时 4 秒的增强尝试，失败或漏检自动切到本地 pico。
- 真实合照实测：12 人合照本地检出 11 张脸。
### 视觉细调（按实拍反馈）
- 移除斜切刷线样式下那条丑黑条：笔刷重画为两端收锋的月牙形，下划线改用点缀色、更细更短。
- 花字更丰富：涂鸦/泡泡/贴纸样式每个字母左上加糖果高光斑；标题两端各一枚小闪光。
- 标题整体缩小一档（84%/78%/72% 画面宽）。
- 人物更大：识别成功时裁剪边距再收紧；未识别兜底放大 1.22 → 1.35 倍。
- 美颜更白亮：亮度 +21%、饱和降一档（高饱和显黄）、柔光层加强，并新增 soft-light 柔白提亮纱，肤色更白净。

## V10.3.1 — 人脸安全线
- 标题尺寸从"只按宽度"改为双重约束：宽度上限 + 人脸安全线（识别出的最高人头再上浮 0.35 个脸高作余量，兼顾漏检的更高个子）。头顶空间不足时标题自动缩小，保证不遮人；空间充足时依旧铺满 84% 宽。
- Q 版人物同样受安全线约束，且保留逐步缩小+上提的终检（最多 4 轮），确保不压任何一张识别出的脸。
- 保底可读字号 90px；仅在"人头几乎顶到画面上沿"的极端照片中，字母描边可能轻碰发梢（约画面高 1%）。

## V10.3.2 — 风格滤镜真正作用于照片
- 修复"一键换风格"感知弱的问题：此前风格只改装饰配色，照片一个像素都不动。现在每种风格自带一套照片调色滤镜（亮度/对比/饱和/色相偏移 + 专属色调纱 + 独立柔光强度），切换风格 = 切换滤镜：
  · 活力：暖调高饱和　· 酷飒：冷蓝高对比　· 可爱：粉嫩柔亮（柔光1.4倍）　· 清爽：白净透气　· Y2K：紫调高冲击
- 柔白提亮层再加强（0.30→0.38），配合默认美颜 55，整体更白亮。
- 风格滤镜与美颜强度相乘叠加：美颜滑杆依然控制整体强弱。

## V10.4.0 — Final Polish
1. **大小滑杆**：点选画面中的人物/标题/贴纸后，编辑区出现对应的大小滑杆（30%–320%），拖动实时生效，替代原来的"缩小/放大"按钮；支持撤销。
2. **新增三个滤镜**：白皙（主打美白，肤色白净提亮）、奶油（暖白奶油调）、胶片（低饱和高对比质感），加上原有 5 个共 8 种风格，每种都真实作用于照片。
3. **默认字号下调一档**：74%/70%/64% 画面宽（少人/中等/拥挤），对齐用户认可的比例。
