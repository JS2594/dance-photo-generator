# PopShot v8

私人课程合照封面生成器。GitHub Pages 静态部署即可使用。

## v8 重点
- MediaPipe Face Detector 优先进行多人主体识别，浏览器原生 FaceDetector 作为回退。
- 智能裁剪 + 照片手动拖拽/缩放兜底；换一版不会重置人工裁剪位置。
- 根据合照人数自动调整视觉拥挤度，尽量避免遮挡真人。
- 活力 / 酷飒 / 可爱 / 清爽 / Y2K 五套视觉主题。
- 标题、Q版人物、Logo、贴纸可拖动、缩放、隐藏、调层级、锁定、撤销/重做。
- 两周组合去重；同星期优先避免重复组合。
- 节日素材只在对应节日窗口出现，普通日期只使用通用素材。
- 记忆课程、美化、风格和未完成草稿；导出前状态检查。
- 输出尺寸 2525 × 1894。

> 第一次打开时，主体识别模块需要联网加载 MediaPipe；加载失败会自动回退，手动裁剪始终可用。


## V9 收口优化
- 课程选择区只保留 Lelepop / Buttscaler / ZUMBA / ZUMBA CAMP 四个真实课程名，不再出现自造课程副标题。
- 成图标题也只使用对应真实课程名；5 个“标题”选项仅改变字体/描边/渐变/刷线等视觉样式。
- ZUMBA CAMP 允许视觉上 ZUMBA 更突出、CAMP 更小，但文字仍严格是 ZUMBA CAMP。
- 删除独立的底部胶囊 Logo；课程字样本身承担 Logo 作用。
- 默认每张成图只放 1 个 Q 版人物。
- 换人物 / 换标题样式 / 换贴纸改为可视化选择面板。
- 裁剪进一步改为主体优先，并继续保留人工拖拽与缩放兜底。

## V9.1 压力测试收敛
- 针对顶部站满人、左右拥挤、低位蹲姿、12人密集等极端布局增加上下标题候选位置。
- 人越多，标题和Q版人物自动适度收敛，但 ZUMBA 仍保持主视觉。
- Buttscaler / ZUMBA CAMP 等较长课程名会按实际可用宽度自动缩放。
- 小贴纸若与人脸安全区冲突会自动隐藏。

## V9.2 极端场景保护
- 增加“标题和Q版人物都位于底部两侧”的布局，专门处理顶部站满人的合照。
- 如果镜面倒影/多人挤满导致所有装饰方案都不安全，自动进入人物优先模式：先隐藏Q版人物和贴纸，只留下缩小后的课程标题。

## V9.2.1 Hotfix
- 修复极端安全模式可能把 Q 版人物隐藏的问题。
- 标题与 Q 版人物现在是必须保留的主视觉；拥挤时先取消贴纸，再缩小并重新找安全位置。
- 旧版本本地草稿不会再把隐藏图层状态带入新版本。

## V9.2.2 Force Visual
- 标题与Q版人物不再依赖 zOrder 或旧草稿状态，render 时强制绘制。
- 标题和Q版人物不能被“删除/隐藏”，仅允许移动和缩放。
- 页面显示实际运行版本号，便于确认 GitHub Pages 缓存是否已更新。

## V9.3
- 页面预览与最终导出严格采用 2525 × 1894 px（约 4:3）。
- 单张成图默认只使用 1 个 Q 版人物。
- 默认“紧密组合”：课程标题与 Q 版人物作为一个视觉模块自动排版。
- 可切换“角落独立”布局。
- 保留照片拖动、缩放、人物/标题/贴纸拖动和尺寸调整。

## V9.3.1 Layout Fix
- 移除标题+Q版人物在底部正中堆叠的默认方案。
- 默认标题位于上方视觉区，Q版人物仅在左下/右下自动选择。
- 进一步收紧合照裁剪，自动轻微放大真人主体，减少天花板和无效留白。

## V10.0 — Curated Final Direction
- 默认每张成图仅使用 1 个 Q 版人物。
- 默认关闭多余小贴纸，减少廉价感和拥挤感。
- 仅保留真实四个课程名作为主标题。
- 标题与人物按 4 套编辑式构图共同布局，不再各摆各的。
- 人越多，标题和人物自动缩小；优先保护真人主体。
- 保留手动调整照片、标题、人物等能力，自动生成不满意时可人工干预。
