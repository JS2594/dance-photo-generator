## v4.0 最终排版修订
- 主体优先的保守智能裁剪，尽量裁掉无效留白而不切掉边缘人物
- 课程标题明显放大，但只占顶部/边缘安全区
- Q版人物与课程小Logo合并成单一视觉模块
- 多人照片采用低装饰密度，最多两个小贴纸
- 相框弱化，统一照片与素材而不抢主体
- 删除额外俗套宣传文案


## v5.0 手动干预
- `for Lisa, and only Lisa ♡` 只保留在操作界面顶部，不会写入生成照片
- 人物 / 课程标题 / 小Logo / 贴纸均可直接在画布上拖动
- 点选图层后可缩小、放大、重置
- 一键生成仍会给出默认协调排版，手动编辑只是可选入口


## v6.0 最终体验版
默认 Logo 为中等尺寸；新增 A/B/C 三版候选、撤销/重做、图层锁定、素材收藏、本地编辑状态保存、简洁/默认/丰富三档，以及底部可展开使用 Tips。已移除“把每一次课后合照，变成专属封面。”；`for Lisa, and only Lisa ♡` 仅存在于操作界面，不进入导出图片。


## v7.0 完善版
- 浏览器支持 FaceDetector 时，自动识别人脸区域用于保守裁剪与标题/人物/Logo避让；不支持时自动回退为保守居中裁剪。
- 人数较多时自动降低装饰密度，优先保留真人主体。
- 上传照片与编辑状态保存到当前设备，意外关闭后再次进入会询问是否继续上次作品。
- 记住上次选择的课程和美化偏好。
