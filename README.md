# PopShot

私人定制课程合照生成工具。

> for Lisa, and only Lisa ♡

## 当前版本
- 输出尺寸：2525 × 1894 px
- 课程：Lelepop / Buttscaler / ZUMBA / ZUMBA CAMP
- 上传照片 → 选课程 → 随机生成 → 可换人物/标题/装饰 → 保存高清图片
- 基础照片美化
- 同课程 14 天内避免完整组合重复
- 连续同星期几同课程避免使用相同完整组合
- 非节日期间不调用节日素材
- PWA，可发布到 GitHub Pages 后添加到手机桌面
- 已替换为确认版 PopShot 相机人物 Icon
- 素材版本更新提示基础机制
