# PopShot V17 Mobile Demo

本版按确认后的手机 Demo 重构，目标是让小白用户直接使用。

## 默认流程
上传课后合照 → 选择课程 → 基础美化 → 一键生成 → 默认成品组合。

## 关键规则
- 默认优先显示「成品组合」。
- 成品组合出现时，不额外叠加自定义 Q 版人物和课程文字。
- 「组合」中可切换：成品组合（推荐） / 自定义组合。
- 成品组合只调整整体大小；自定义组合可选择 Q 版人物、课程字样并拖动/缩放。
- 首页保留四个课程：Lelepop / ButtScaler / ZUMBA / ZUMBA CAMP。
- 基础美化固定单行横向滑动，不换行。
- 主操作区为：组合 / 相框 / 贴纸 / 调整照片 / 更多。
- 所有主要按钮扩大手机点击区域。
- 输出画布仍为 2525 × 1894。

## 后续人工替换成品组合
直接替换以下目录中的 PNG，文件名保持不变即可：
- public/custom-combos/lelepop/
- public/custom-combos/buttscaler/
- public/custom-combos/zumba/
- public/custom-combos/zumba-camp/

不需要自己拼接代码。

## V17.3 清晰度专项
- 本轮只优化清晰度链路，不调整色彩参数。
- 最终成品不再固定 2525×1894。
- 保持 4:3，按当前裁剪区域的原始有效像素决定输出尺寸。
- 手机 Canvas 仅用于预览；保存时创建独立高分辨率 Canvas，从原始照片与原始素材重新绘制。
- PNG 无损导出，不设置 JPEG quality，不做有损压缩。
- 不把低分辨率裁剪区域强制放大成假高清。
- 页面会显示“原图尺寸 → 实际导出尺寸”，方便直接核验。

## V17.4 清晰度锁定 + 课程响应
- 锁定原图级 4:3 PNG 输出；默认使用原图最大可用 4:3 裁剪区域。
- 人脸识别只影响裁剪位置，不再把裁剪区域缩成几百像素。
- 默认 photoZoom=1；只有用户主动放大才减少有效输出像素。
- 本轮没有调整任何色彩参数。
- 课程卡片移除下方说明小字。
- 课程点击后立即更新选中态，不等待成品组合 PNG 加载。
- 快速连续切课程加入请求序号保护，旧素材请求不会覆盖最后选择。
- 空闲时预热四个课程的第一张默认搭配，提高第一次切换速度。
- 一键生成/换一版增加 busy 状态，避免连续点击造成重复任务。

## V17.5
- 默认构图适度放大真人，并尽量保留左右各约一个站位。
- 默认搭配固定使用每个课程 custom-combos 文件夹中的 *_01.png；“换一版”才轮换其它人工成品组合。
- 一键换风格仅在自定义搭配生效。
- 贴纸默认更大，添加后可直接在成图上拖动；推荐与通用分离。
- 新增 public/sticker-library/，可按 README 直接补充 sticker_01.png ~ sticker_30.png，缺图自动忽略。

## V17.5.1 修复
- 只有线上版本高于当前版本时才提示更新；当前版本更高时显示部署同步中。
- “更新并刷新”会注销旧 Service Worker、清空 Cache Storage 后重新加载。
- 修复草稿恢复弹窗“继续编辑”按钮白字白底。
- 默认搭配锁定各课程 `_01.png` 成品组合。
- 默认搭配加载失败时不再静默切为自定义搭配，而是明确提示素材未加载。
- 四个课程默认搭配提前预加载。
- 本版不改清晰度、不改色彩。
